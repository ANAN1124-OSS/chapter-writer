# 章节写作器 v0.4

给写个人自用的 Windows 桌面写作工具：**整本书一键保存、绝不丢稿**；新建章节自动生成「第12章：」这样的标题，你只填名字。

技术形态：Electron + 原生 HTML/CSS/JS（无框架），Windows 安装包 + 开发版两种用法。

---

## ⚠️ 先看这三条（本版是「完全手动保存」）

1. **保存是手动的，只有一个例外**：平时只有按 `Ctrl+S` 或点「保存」按钮时，正文才写进磁盘。例外是**新建 / 插入章节之前**——当前章有未保存修改时会**自动帮你存一下**再建新章（保存失败就停下报错、不建新章），省得每次建章都被问一次。
2. **默认不做每日备份**：应用默认不备份任何东西。只有在「设置」里手动打开**可选每日快照**（默认关）后，才会在每次保存时把当天第一次保存的**上一版**留一份到书内 `_trash\快照-YYYYMMDD\`，并按保留天数自动清理旧快照。**改坏了、崩溃了、关机了，最终还是靠你自己拷的副本。**
3. 切章节、关窗口之前，如果当前章有未保存修改，应用会弹窗让你选「保存 / 不保存 / 取消」，**不会静默丢失，也不会偷偷替你保存**。
   **导出 / 复制不用先保存**：当前章在编辑区里还没保存的内容也会一起写进导出结果（只参与拼接，不写盘），不会因为忘记按保存而导出旧内容。

> 强烈建议：把书架目录（默认在「文档」下的 `我的小说` 文件夹）放进 OneDrive / 坚果云等同步盘，或打开 Windows 的「文件历史记录」。
> 即使打开了应用内的每日快照，也建议保留一份外部备份（同步盘 / 移动硬盘）——快照只覆盖「保存前一刻」，防不了整块硬盘坏掉。

## 环境要求

**安装版（作者日常用）**：Windows 11 / Windows 10 1809+，**不需要装 Node**。

**开发版（改代码时用）**：

- Windows 11（Windows 10 1809+ 也可）
- Node.js ≥ 22（开发机实测 v24.22.1）
- pnpm ≥ 10（实测 12.11.2）

## 安装与启动

### 方式一：安装包（推荐，不用命令行）

**下载**：从 [GitHub Releases](https://github.com/ANAN1124-OSS/chapter-writer/releases/latest) 下载 `chapter-writer-0.4.0-win-x64-setup.exe`，或者直接用本机打包产物 `dist\chapter-writer-0.4.0-win-x64-setup.exe`。

安装：

1. 安装包**没有代码签名**，Windows 可能弹「已保护你的电脑」→ 点「更多信息」→「仍要运行」。
2. 可以自己选安装目录（默认装到当前用户目录，不需要管理员），安装完有**桌面快捷方式**和**开始菜单**入口。
3. 卸载：Windows「设置 → 应用」里卸载，或开始菜单里「卸载」。**卸载不会删你的小说**（书架目录默认在「文档」下、可自行修改，应用配置在 `%APPDATA%\chapter-writer`；安装包也特意没勾「卸载时删除应用数据」）。

> 安装版和开发版**共用同一份配置和书架设置**（同一个 `%APPDATA%\chapter-writer\config.json`），换着用不会丢设置。

### 方式二：开发版（代码方式）

```bash
cd D:\code\chapter-writer
pnpm install        # 第一次会下载 Electron（约 100MB，走 npmmirror 镜像）
pnpm start          # 启动应用
```

> **如果 `pnpm start` 报「无法加载文件 …pnpm.ps1，因为在此系统上禁止运行脚本」**
>
> 这是 Windows PowerShell 5.1 的默认执行策略（Restricted）拦住了 pnpm 的 `.ps1` 垫片，不是项目的问题。
> 任选一种即可：
>
> 1. **双击项目根目录的 `启动写作器.cmd`**（最省事，不用记命令）；
> 2. 在当前 PowerShell 里改用 **`pnpm.cmd start`**（走 `.cmd` 垫片，不受脚本策略限制）；
> 3. 一次性放开当前用户策略（无需管理员）：`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，之后 `pnpm start` 就能用；想改回去：`Set-ExecutionPolicy -Scope CurrentUser Undefined`。
>
> 用 PowerShell 7（`pwsh`）打开终端也可以直接用 `pnpm start`。

说明：

- `.npmrc` 已配置 `electron_mirror=https://npmmirror.com/mirrors/electron/`，避免卡 GitHub。
- 某些宿主环境（例如某些 AI 工具、CI）会带 `ELECTRON_RUN_AS_NODE=1`，会让 Electron 退化成纯 Node 而启动失败。
  `pnpm start` 实际执行的是 `scripts/start.js`，它会自动清掉这个环境变量再启动。
  （**安装版**从桌面/开始菜单双击启动不受影响；只有在那种环境里用命令行直接跑 exe 才要先清掉它。）
- 数据目录不在项目里：默认在当前用户「文档」下的 `我的小说` 文件夹，可在应用「设置」里改。

## 打包（开发者/维护用）

```bash
pnpm run icon       # 重新生成图标（build/icon.ico / icon.png，纯 Pillow 绘制，需要 python）
pnpm run dist       # 打 Windows 安装包 → dist\chapter-writer-<版本>-win-x64-setup.exe（NSIS，x64）
pnpm run dist:dir   # 只打免安装目录 → dist\win-unpacked\章节写作器.exe（改完快速验证用）
```

- 配置在 `package.json` 的 `build` 字段：appId、产品名、NSIS 安装器选项（可选目录、桌面/开始菜单快捷方式、中文界面）。
- 国内网络打包时如果下载 Electron/NSIS 卡住，先设镜像：
  `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`、
  `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`。
- 目前**没有代码签名**（个人自用省掉证书），所以每台新机器首次安装会看到 SmartScreen 提示。
- 安装包产物在 `dist/`（已加进 `.gitignore`，不进仓库）；`build/icon.*` 是图标源文件，会进仓库。
- 产物文件名用 **ASCII**（`chapter-writer-<版本>-win-x64-setup.exe`）：`gh` 在 Windows 上传中文文件名会被吞成 `-0.1.0-.exe`，所以发布资产别用中文名；安装后的程序显示名/快捷方式仍是「章节写作器」。
- 发布到 GitHub：`gh release create v<版本> "dist/chapter-writer-<版本>-win-x64-setup.exe" --title "章节写作器 v<版本>" --notes-file <说明.md>`（`gh` 走 HTTPS，国内需 `HTTPS_PROXY`）。

## 数据在哪

```
%USERPROFILE%\Documents\我的小说\   ← 书架目录（默认位置，可在设置里改）
├─ _trash\                       ← 回收站不可用时，删除的整本书移到这里（可人工找回）
├─ 星海旅人\                     ← 一本书 = 一个文件夹
│  ├─ 书目.json                  ← 书名、章节顺序、章名、章节状态/备注（唯一事实来源）
│  ├─ 书目.json.bak              ← 上一次写入前的版本（json 写坏时用）
│  ├─ 001-未命名.txt             ← 创建序号 + 名字，文件名永不修改
│  ├─ 002-夜雨.txt
│  ├─ 003-未命名.txt
│  ├─ 003-未命名.txt
│  └─ _trash\                    ← 删除的章节、替换/整理/还原前备份、可选每日快照，不真删
│     └─ 快照-YYYYMMDD\          ← 只有开启「可选每日快照」后才有
└─ 另一本草稿\
```

应用配置单独存放在 `%APPDATA%\chapter-writer\config.json`（书架目录、窗口位置、全局显示设置、每本书的显示设置覆盖 `bookDisplay`、排版规则、上次导出的目录、书架顶部「继续上次写作」的 `lastBook` 记录、可选每日快照的 `snapshotEnabled` / `snapshotKeepDays`、每日写作目标的 `dailyGoal`）。

每日字数统计单独存放在 `%APPDATA%\chapter-writer\stats.json`（按本地日期 + 书 id 记「保存时新增的正字数」，**绝不写进书架/书内**；文件坏了会归档成 `stats.json.corrupt-时间戳` 再从空统计继续，不影响正文）。

> `lastBook` 只记“上次写的是哪本书、哪一章、什么时候”，给书架顶部的「继续写」入口用；**打开书回到哪一章仍以书内 `书目.json` 的 `lastOpenChapterId` 为准**。删掉配置文件只会丢这些便利记录，不会动书库。

关键规则：

- **章节显示名 = 「第N章：名字」，N 由章节顺序现算，不写死**。插入/删除后章号自动重排。
- **插入章节只改 `书目.json` 记录，不重命名任何文件**。所以文件名前缀是「创建序号」，不需要和显示章号一致。
- 章节 txt 里只有正文：UTF-8 无 BOM、`\r\n` 换行，记事本直接打开不乱码。
- **章节状态（草稿 / 待修 / 完稿）和一句话备注只存在 `书目.json` 里**，是可选字段；标记状态、写备注**不会碰章节 txt 一个字节**，旧书目没有这两个字段也照常打开（默认草稿）。
- **`书目.json` 顶层有 `schemaVersion`（当前为 1）**：旧书没有这个字段也照常打开；打开不会为了补版本号而写盘，等下次正常写盘（改名 / 保存 / 改状态）时才补上（首次扫描补字数缓存也会写一次书目）。比本应用新的版本号会原样保留，不会被旧版应用写成旧格式。
- 改名（书名、章名）只改 json，文件夹名/文件名都不动。
- 同步盘（OneDrive / 坚果云等）两边同时改过时，书文件夹里可能出现 `书目 (conflicted copy 1).json`、`001-起风-冲突副本.txt` 这类**冲突副本**。书架会在书卡上标黄提示，点开能看文件名并打开书文件夹；**应用只提示，不自动合并、不删除，也不把它们当成章节**（从目录重建书目时同样会跳过）。
- **书内 `_trash` 是备份区**：替换、整本整理、还原前、删除章节的备份都在这里，加上书文件夹根部的上一版 `书目.json.bak`，统一在「本书历史」里查看。面板只**读**备份；还原前会先把书里现在的内容再备份一份到 `_trash\还原前备份-时间戳\`。除了**开启每日快照后**按保留天数清理应用自己生成的 `快照-YYYYMMDD` 目录，其它备份不会被自动清理。

## 怎么用

| 操作 | 方式 |
|---|---|
| 新建书 | 书架 →「＋ 新建一本书」 |
| 导入小说 | 书架右上「导入小说」，选一个或多个文件夹。先选导入方式：**按原文章节导入（默认）——按原文的「第X章 / 第X幕 / 第X话 / 楔子 / 番外 / 后记 / 附录」等标题拆成多章，章名照抄原文、正文一字不改（支持上百字的长标题和奇怪标点写法）**；或「整本一章」——不拆章，整本放在一章「全文」里（UTF-8 源文件按字节原样复制）。三种来源自动识别：① 章节写作器书（含 `书目.json`）整本复制；② 一本书的章节目录（txt 名如 `001-xxx.txt`）合成一本书；③ 一堆独立小说 txt（一个放满小说 txt 的文件夹）→ 每个 txt 一本书。自动识别 UTF-8 / UTF-16 / GBK 编码；只复制不移动源文件；重名自动加 `-2`；大批量导入显示进度 |
| 删除小说 | 鼠标移到书卡右上角「⋯」→「删除这本书…」，或右键书卡 → 删除。整本书移到 Windows 回收站（回收站不可用时移到书架 `_trash`），不会真删 |
| 打开书 | 点书卡；如果 `书目.json` 损坏，卡片会标红并提供修复 |
| 同步冲突副本提示 | 书架目录放在 OneDrive / 坚果云里时，同步盘可能生成 `*conflicted*` / `*冲突副本*` 文件。书卡会标黄「⚠ 检测到同步冲突副本（N 个）」，点一下看文件名、并可「打开书文件夹」手动处理。写作器**只提示，不自动合并、不删除**；这些副本也不会出现在章节列表里 |
| 本书历史 | 写作页「导出 ▾ → 本书历史…」或右键书卡 →「本书历史…」：把书内 `_trash` 的**替换 / 整理 / 还原前 / 每日快照 / 删除章节**备份和书文件夹里的上一版 `书目.json.bak` 按时间新→旧列出来，并标出每个文件**还在不在书里**。可以**预览**、**还原单章**、**还原整组**：只还原现在仍在书里的章节（已删章节不会偷偷复活），还原前先把当前内容备份到 `_trash\还原前备份-时间戳\`。删除的章节可以一键**放回书文件夹**（不自动加回章节列表、同名文件不覆盖）；书目备份只供查看，不提供覆盖还原 |
| 可选每日快照 | 「设置 → 数据安全」里打开（**默认关**）+ 选保留天数（1–90 天，默认 7）。开启后每次 `Ctrl+S` **成功保存**时，当天第一次保存会把这一章的**上一版**复制到书内 `_trash\快照-YYYYMMDD\`（同一章当天只留第一份，不重复、不覆盖）；保存时顺手清理超过保留天数的「快照-YYYYMMDD」目录，**只清理应用自己生成的快照目录**，不认识的目录 / 散文件一律不动。快照可在「本书历史」里预览、还原单章/整组。**这不是自动保存**：正文仍然只在你按保存时才写盘 |
| 每日字数统计 + 写作目标 | 书架顶部显示「今天 +N 字」，写作页状态栏显示「今日 N 字」。**只统计按保存（`Ctrl+S` / 建章前自动保存）时新增的正字数**：没保存的编辑不算，删字也不会倒扣当天进度。想设目标就去书架 →「设置 → 写作统计」填每日目标（0 = 不设目标，默认关）：状态栏会出现一条细进度条，书架也会显示目标和完成百分比，达标后标「已达标」；设置里还有**近 30 天柱状图**。统计数据只存在 `%APPDATA%\chapter-writer\stats.json`，不进书库、不改 `书目.json` / 章节 txt |
| 搜索书架 | 书架右上搜索框（或按 `Ctrl+F`）：输入即过滤，**按书名 / 文件夹名 / 章节名**搜（不读正文，281 本书也秒出）。章节名命中的书卡会显示「章节命中：第N章：xxx」；`Enter` 打开第一本匹配的书，`Esc` 清空 |
| 新建章节 | 左栏底部「＋ 新建章节」，输入章节名（可留空 = 未命名）。**建章前如果当前章有未保存修改，会自动先保存当前章**（不弹窗；保存失败就停下报错，不会带着没存的内容建新章） |
| 在中间插入 | 当前章标题栏「＋ 插入」，或章节右键 → 在此前/后插入。同样会先自动保存当前章 |
| 切换章节 | 单击左栏章节；有未保存修改时会弹窗 |
| 继续上次写作 | 书架顶部会显示「继续写《书名》· 第N章」，点一下直接打开那本书并回到上次编辑的章节（记录在配置文件的 `lastBook` 里；打开书后仍以书内 `书目.json` 的 `lastOpenChapterId` 为准）。上次那本书被删掉、改名到书架外或损坏时，入口自动隐藏；只记最近一本 |
| 快速跳章 | 写作页按 `Ctrl+G`：输入章号（`12`、`第12章`、`12章`，全角数字也认）直接跳到第 12 章；或输入章名的一部分（如「夜雨」）列出匹配章节，点一条或回车跳第一条。章号超出范围会提示「本书共 N 章」；跳章只切换章节、不改正文，有未保存内容时照常问「保存 / 不保存 / 取消」 |
| 拖拽排序章节 | 左栏**按住章节上下拖动**，松手即改顺序；只改 `书目.json` 数组顺序，**章节文件永不重命名**，章号按新顺序自动重算。拖到列表顶/底会自动滚动 |
| 分卷 | 侧栏底部「＋ 新建卷」建卷；卷在章节列表里显示成**可折叠的分组**。右键卷：重命名卷 / 在此卷末尾新建章节 / 删除卷（卷里的章回「未分卷」，**不删章、不动文件**）。右键章节 →「移到卷…」可把章移到任意卷或移回未分卷。**章节可以直接拖到别的卷**（拖到卷标题上 = 放进那一卷，拖到某章上 = 插到它前/后）；卷右键还能**上移卷 / 下移卷**调整卷序。**章号不变**（仍是全书连续编号）。导入的原文分卷会自动带进来；导出 / 复制时每卷前多一行卷名；「导出 TXT…」还能**按卷导出**（文件名默认 `书名-卷名.txt`） |
| 章节状态 + 备注 | 每章名字前有一个**状态小圆点**：灰 = 草稿（默认）、黄 = 待修、绿 = 完稿。右键章节 →「标记为完稿 / 待修 / 草稿」；右键 →「编辑备注…」写一句话（最多 200 字，悬浮章节可看）。书卡上会显示「完稿 X/Y 章」。**只写 `书目.json`，正文 txt 一个字节不动**；没标记过的章默认显示灰点，书目里也不会多出字段 |
| 查找替换 | 写作页右上「查找」或 `Ctrl+F`：范围可选**当前这一章 / 整本书**；结果显示「第几章、命中几处、带上下文的片段」，点结果直接跳过去。**「替换这一处」**只替换光标处这一处、自动选中下一处（只用于当前章、不写盘、`Ctrl+Z` 可撤销）；「全部替换」在整本范围会先弹确认，并把原文备份到书内 `_trash\替换备份-时间戳\`；整本替换后可在同一面板**「还原到替换前」**一键退回（还原前再把当前内容备份到 `_trash\还原前备份-时间戳\`） |
| 保存整本 | `Ctrl+S` 或右上「保存」；保存时会顺带校验全书章节文件是否齐全 |
| 重命名章节 | 双击章节，或右键 → 重命名（只改显示名） |
| 删除章节 | 右键 → 删除（文件进 `_trash`，不真删） |
| 右键菜单 | 在**正文、章节名、书名、书架搜索框、查找替换输入框**这些能填文字的地方点右键：弹出中文菜单「剪切 / 复制 / 粘贴 / 全选」。没选中文字时「剪切 / 复制」是灰的，剪贴板里没文本时「粘贴」是灰的；粘贴走系统剪贴板，`Ctrl+Z` 可撤销。章节列表、书架卡片右键仍是各自的应用内菜单，不会串 |
| 复制整本 | 右上「导出 ▾」→ 复制整本到剪贴板。提示里会显示章数和字数；当前章没保存时，**编辑区里的最新内容也会一起复制**（不写盘） |
| 复制本章（平台格式） | 右键章节 →「复制本章（平台格式）」，或按 `Ctrl+Shift+C`。只复制**这一章的正文**（不含章名，起点/晋江后台的章名是单独一栏），并套上「**段首缩进两格 + 空一行（含缩进）**」再进剪贴板，粘过去空行不会塌。**不写盘**；当前章有未保存修改时，编辑区里的最新内容同样参与。点的是哪一章就复制哪一章（右键非当前章时读磁盘） |
| 导出 TXT | 右上「导出 ▾」→ 导出 TXT…，先在对话框里选范围：**全书 / 按卷 / 第 X–Y 章**（没分卷的书不显示「按卷」）。UTF-8 带 BOM、CRLF，记事本友好；按卷 / 按章只导出选中的部分，**章号仍按全书连续编号**（不会从第 1 章重排）。默认文件名跟着范围走：`书名.txt` / `书名-卷名.txt` / `书名-第X-Y章.txt`（保存时可改）。当前章未保存的内容同样参与；提示里显示这次导出的章数和字数。**保存对话框默认打开在上一次导出的文件夹**（没导出过才默认「文档」；那个文件夹被删了会自动退回「文档」）。有分卷的书，每卷前会多输出一行卷名 |
| 打开书文件夹 | 右上「导出 ▾」→ 打开本书文件夹 |
| 设置 | 书架右上「设置」= **全局默认**：书架目录 + 显示设置（字体/字号/行间距/字间距/左右边距/正文宽度/背景主题）+ **写作统计**（每日目标 / 近 30 天柱状图）+ **可选每日快照**（开关 / 保留天数）。写作页「排版 ▾ → 正文显示设置…」改的是**当前这本书**的设置（只影响本书，可「恢复本书默认」）；章节栏宽度也是按书记住 |
| 调整章节栏宽度 | 写作页拖动章节栏与正文之间的分隔条即可；双击分隔条恢复默认宽度。宽度**按书记住**（每本书可以不一样），下次打开这本书保持 |
| 智能排版（一键整理本章） | 写作页右上「排版 ▾」→「一键整理本章…」：按规则整理**当前这一章**（段首缩进 2 字符 / 0 字符 / 不处理、段间空行、空一行（含缩进）、删行尾空白、中文旁半角标点转全角、**可选的直引号转中文弯引号 / 省略号**），先给预览再套用。套用后仍是**未保存**状态，`Ctrl+S` 才写盘；`Ctrl+Z` 或「排版 → 撤销上次整理」可退回（最多连退 50 步） |
| 一键整理本书 | 写作页右上「排版 ▾」→「一键整理本书…」：用上次的规则把**整本**排一遍。先**只读预检查**（统计几章会被改）→ 确认框列出规则和要改的章 → 写盘前把要改的章备份到书内 `_trash\整理备份-时间戳\` → 逐章写盘并在右下角显示进度 → 完成后自动重载当前章。已经是整理后格式的章不会动、也不重复备份；**没有改动时不弹框，直接提示**。这是显式写盘动作，不走「撤销上次整理」 |
| 正文显示 | 写作页右上「排版 ▾」→「显示：紧凑 / 标准 / 宽松」一键切换行间距、字间距、左右边距、正文宽度；或「设置」里细调，还能换**自定义字体文件**、**夜间 / 牛皮纸 / 网格纸**背景。这些改动只作用于**当前这本书**（书架 →「设置」里改的是全局默认）。**只改显示，不动正文一个字** |
| 撤销整理 | `Ctrl+Z`（整理后立刻按），或「排版 ▾」→「撤销上次整理（可撤销 N 步）」；快照最多 50 步，原文会回到编辑区，仍未保存 |

快捷键：`Ctrl+S` 保存、`Ctrl+F` 查找替换（在书架页是聚焦搜索框）、`Ctrl+G` 跳章（输入章号或章名）、`Ctrl+N` 新建章节、`Ctrl+Shift+C` 复制本章（平台格式）、`Esc` 关弹层 / 清空书架搜索、`Ctrl+Shift+I` 开发者工具（调试用）。

## 查找替换与章节排序

**查找替换**（右上「查找」或 `Ctrl+F`）—— **字面量**查找，不搞正则（`.*` 就只是三个字符），避免误伤全稿：

- 范围「当前这一章」：只算编辑区，不写盘；替换只改编辑区（未保存），`Ctrl+Z` 可撤销。
- **「替换这一处」**（只用于当前章）：只替换光标处的这一处，替换完自动选中下一处，可以连续按；改的只是编辑区，`Ctrl+S` 才写盘。整本范围下这个按钮不执行，避免误以为只改一处。
- 范围「整本书」：点「查找」列出命中的章节和上下文片段，点一条就跳到那一章并选中第一处。
- 「全部替换（整本）」：**先弹确认**（几章、几处），确认后才写盘；写盘前把改动的原章节**备份到书内 `_trash\替换备份-YYYYMMDD-HHMMSS\`**。
- **整本替换点错了可以退**：替换后打开「查找」面板，下方会出现「最近一次整本替换的备份」→ 点「还原到替换前…」，二次确认后把备份覆盖回书里；并且还原前会先把**当前内容**再备份一份到 `_trash\还原前备份-时间戳\`（所以还原这一步也能回头）。只还原最近一次替换；更早的备份在 `_trash` 里可手动拷回。
- 整本替换前如果有未保存的修改，会先问「保存 / 不保存 / 取消」，不会静默丢掉。

**章节拖拽排序**：

- 左栏按住章节上下拖动，松手生效；拖到最上面/最下面会自动滚动。
- 只改 `书目.json` 的顺序：**章节文件不移动、不改名**，内容和文件名的对应关系不变。
- 显示章号（第N章）按新顺序现算，所以拖完章号会自动重排。

## 排版（写作页右上「排版 ▾」）

排版功能参照口袋写作（`D:\APP\kdwrite`）的「排版设置」补齐：智能排版（文字级）+ 字体 / 间距 / 背景（显示级），两半互不干扰。

**1. 智能排版（改 txt 内容，仅当前章）** —— 你点「一键整理本章…」才会执行：

| 选项 | 默认 | 说明 |
|---|---|---|
| 段首缩进 | 缩进 2 字符 | 三选：**缩进 2 字符**（先去掉原有行首空白，再统一加两个全角空格 `　　`）/ **缩进 0 字符**（只去掉缩进）/ **不处理缩进**（保留原样） |
| 段落之间 | 空一行 | 四选：保持原样 / 空一行 / **空一行（含缩进）** / 不空行（紧凑） |
| 删除每行行尾空白 | 开 | 只删行尾的空格、制表符、全角空格 |
| 中文旁边的半角标点转全角 | 开 | `, . ; : ! ?` → `，。；：！？`；**只在中文旁边转**，`3.14`、`www.a.com`、`12:30`、`A.开端` 这类不动 |
| 直引号转中文弯引号 | 关 | `"…"` → `“…”`；**只在中文语境里转**，英文撇号（`don't`）、英文引语（`"Hi"`）、`他叫"Jack"` 这类不动 |
| 省略号 | 关 | 连续 3 个以上英文句点 → `……`；数字（`3.14`）、网址（`www.a.com`）里的点不动 |
| 删除中文之间的多余空格 | 关 | 可能改变语感，默认不勾 |

- **空一行（含缩进）**：空行里放两个全角空格（`　　`）。有些平台/软件会吃掉纯空行，粘过去就粘成一坨；带缩进的空行不会丢（口袋写作把这个叫「解决粘贴后丢失空行」）。
- **引号 / 省略号两项默认关**：改了会动正文标点，所以不默认打开，由你在对话框里勾；勾选框旁边有说明，预览里会给出转换数量。
- 对话框里先看**预览和改动统计**（几段、缩进几段、删几处空白、转几个标点、转几个引号/省略号），确认后才套用。
- **套用 ≠ 保存**：结果只进编辑区，窗口标题仍有 `*`，按 `Ctrl+S` 才写盘——和本应用「完全手动保存」一致。
- **可撤销**：`Ctrl+Z`，或「排版 ▾」→「撤销上次整理」。撤销同样只是改编辑区，不会写盘；内存快照最多 50 步，关掉应用后不可撤销。
- **只处理当前章**，不会碰别的章；章名、`书目.json` 一概不动。
- **光标不会乱跳**：整理/撤销后光标按原位置映射回同一段落，长章里接着写不会插到全章最前。
- 重复整理是安全的：已经整理过的正文再整理一次不会重复加缩进、不会重复转引号。

**整本一起整理：排版 ▾ →「一键整理本书…」**（显式写盘动作，v0.4 起）

- 规则直接沿用你上次在「一键整理本章」里定的那套，不用重新勾。
- 先做**预检查（只读）**：统计全书共几章、其中哪几章会被改动，一个字节都不写。
- 弹确认框，列清「规则、共几章、哪几章会改、写盘前会先备份」，点「开始整理」才真正执行。
- 写盘前把**要改动的原章节**复制到书内 `_trash\整理备份-时间戳\`；没改动的章既不备份也不重写（所以反复点也不会越备越多）。
- 逐章原子写盘，右下角显示「正在整理整本书：N/M 章」；整理完自动重载当前章、同步书架字数。
- **当前章有未保存修改会先问**：「保存后整理 / 不保存（按磁盘内容）/ 取消」。
- 已经是整理后格式的书再点一次**不会弹框**，只提示「没有可改的地方」。
- **整本整理不进「撤销上次整理」**：它是直接写盘的显式动作。要退回只能把 `_trash\整理备份-时间戳\` 里的 txt 手工拷回书文件夹（应用内还没有「一键还原整本整理」）。

**2. 正文显示（一字不动）** —— 「显示：紧凑 / 标准 / 宽松」或「设置」里细调：

| 项 | 可选值 |
|---|---|
| 正文字体 | 宋体 / 黑体 / 楷体 / **自定义字体文件**（.ttf / .otf / .ttc，选一次即可；只读取、不复制文件） |
| 字号 | 16–24 |
| 行间距 | 1.6 / 1.8 / 1.95 / 2.2 / 2.4 |
| 字间距 | 0 / 0.02 / 0.05 / 0.08 em |
| 左右边距 | 16–120 px |
| 正文宽度 | 通栏，或 720–1000 px 居中 |
| 背景主题 | 原纸白 / 米黄（护眼）/ 豆绿（护眼）/ **夜间（深色）** / 牛皮纸（纹理）/ 网格纸（纹理） |

- 这些只改 CSS，**不写任何正文**；设置里改动会实时预览，点「取消」恢复原样，点「保存设置」才记住。
- **按书记忆**（v0.3 起）：书架右上「设置」改的是**全局默认**；在写作页里用「显示：紧凑 / 标准 / 宽松」、「正文显示设置…」或拖章节栏改的，只记在**当前这本书**上，换书会自动切回那本书自己的设置。写作页设置弹层底部有「恢复本书默认」，点了就回到全局。
- 自定义字体只记住文件路径：**换电脑或挪走字体文件后会自动退回宋体**，重新选一次即可。
- 夜间主题是新配的一套深色纸色 + 浅色墨色，不影响你的 txt。

> 说明：正文是纯文本 textarea，「视觉上的段首缩进」不能只靠 CSS 做，所以缩进是作为文本真的写进 txt 的（这也是导出/复制后仍然整齐的原因）。背景图片 / 背景特效 / 主题色 / 会员主题这些口袋写作里的附加项没有做（纯文本编辑器不需要，也避免往书库里塞图片文件）。

## 防丢稿设计（为什么敢叫绝不丢稿）

虽然不做自动保存，但底层仍然为「不丢稿」做了这些：

1. **所有写盘都是原子写**：临时文件 → fsync → rename（失败重试 3 次）。不会出现写一半的半截文件。
2. **`书目.json` 每次写入前保留上一版 `.bak`**：json 写坏可以从上一版恢复。
3. **删除不真删**：章节文件移到 `_trash\{时间戳}-{原文件名}`。
4. **未保存状态四处可见**：窗口标题前 `*`、状态栏橙点、保存按钮高亮、章节名后 `•`。
5. **三处拦截**：切章、关窗、返回书架，都会先问。**导出 / 复制不拦**：当前章未保存的内容会直接拼进导出结果（不写盘），导出完仍保持未保存状态。
6. **关窗保存失败会阻止退出**：弹「返回保存 / 放弃修改退出」，不会静默关掉。
7. **外部修改检测**：用记事本改了当前章节后，切回应用会提示「重新加载 / 保留我的」。
8. **损坏恢复**：`书目.json` 坏了，可以从 `.bak` 恢复，或按目录里的 txt 文件名重建书目（损坏文件改名为 `.corrupt-时间戳` 保留）。
9. **保存失败不更新「已保存」状态**：状态栏红字显示具体错误。
10. **整本替换前自动备份**：改动的原章节先复制到书内 `_trash\替换备份-时间戳\`，再原子写盘；应用内可「还原到替换前」一键退回，还原前还会把当前内容再备份一份到 `_trash\还原前备份-时间戳\`；这些备份不会被自动删（每日快照是唯一例外，见下一条）。
11. **配置坏了不会悄悄回默认**：`config.json` 损坏时会先归档成 `config.json.corrupt-时间戳` 再回默认值，并在界面上提示一句（否则书架路径会突然变回「文档\我的小说」，像书全丢了一样）。
12. **可选每日快照（默认关）**：开启后每次保存前把当天第一次的上一版复制到 `_trash\快照-YYYYMMDD\`，同章每天一份、只增不覆盖；按保留天数清理时只删**名字严格是 `快照-YYYYMMDD`** 的目录，别的备份 / 文件 / 乱写目录一律不碰。快照失败不会阻塞保存，最多在保存结果里带一句原因。
13. **每日字数统计不写书库**：只把「保存时新增的正字数」记到 `%APPDATA%\chapter-writer\stats.json`（按本地日期 + 书 id）；不统计未保存内容，删字不倒扣，统计读写出错只影响数字显示，**绝不阻塞正文保存**。每日目标是可选的全局设置（0 = 不设）。

## 已知限制（v0.4 仍有意不做）

- 安装包**未签名**：首次安装 Windows SmartScreen 会提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可；没有自动更新（升级要重新装一次新包）
- 无自动保存、**默认无每日备份**、无云同步、无多端（按作者要求；自动保存只有「新建 / 插入章节前自动保存当前章」这一处例外；每日备份是手动打开的「可选每日快照」，默认关）
- 无富文本、无大纲、无设定库、无 AI 辅助（需求砍掉）
- 「智能排版」默认只处理当前章；整本要排得显式点「一键整理本书…」（会直接写盘，写前备份）
- 整本整理**没有「撤销上次整理」**：它是直接写盘的显式动作，要退回请打开「本书历史」→ 选 `整理备份-时间戳` →「还原整组 / 还原单章」（还原前会把当前内容再备份一份）
- 标点整理覆盖 `, . ; : ! ?` 六种，**直引号和省略号要在对话框里单独勾**（默认关）；不做「智能引号配对」这类不可控转换，避免误伤对话
- 撤销整理只有内存快照（最多 50 步）：**关掉应用后不可撤销**，所以整理后建议扫一眼再 `Ctrl+S`
- 「替换这一处」只支持当前章；整本范围仍是「全部替换」（写盘前自动备份），不支持「整本只替换某几处」
- 查找面板的「还原到替换前」只针对**最近一次**替换；更早的替换备份请用「本书历史」还原单章 / 整组（只还原现在仍在书里的章节），除每日快照外备份目录不会自动清理
- **本书历史只扫描书内 `_trash` 顶层目录 / 散文件和书文件夹根部的 `书目.json.bak`**，不递归子目录；`书目.json.bak` 只供预览，**不提供一键覆盖还原**（书目损坏请走书卡「修复」）；删除章节放回书文件夹后**不会自动加回章节列表**（需要时用「从目录重建」，注意重建会生成新的书目 id、丢掉状态/备注与按书显示设置）
- **每日快照不是自动保存**：只在 `Ctrl+S`（含建章前的自动保存）时留一份，且每章每天只留当天第一份（同一天再改再存不会刷新快照）；开快照**不会**让你少丢没保存的内容
- 每日快照只按**本机本地日期**分目录，跨时区/手动改系统时间会显示成另一天的目录；保留期只按目录名里的日期算，不读文件时间
- 快照目录的清理**只认名字严格等于 `快照-YYYYMMDD` 的目录**，并且只在这种目录里删；把别的备份改名成这个格式会被当成快照清理，请别这么做
- 没有「快照总览 / 一键清空快照」：要腾空间可以到书内 `_trash` 按文件夹名手动删，或在设置里把保留天数改成 1 天（下次保存自动清旧目录）
- **每日字数只统计「保存动作」带来的正增量**：没按保存的编辑、切章、导出、整理（未写盘时）都不算；删字/替换变短**不会倒扣**当天进度。如果章节在应用外被别的程序改过，应用按书目里缓存的上次字数算增量，这一次的统计可能和你的手感略有出入
- 每日字数统计按**本机本地日期**归天（跨时区/手动改系统时间会记到另一天）；`stats.json` 只保留最近约 400 天，更早的日期在下次记录时清掉（不影响书库）。目标只有**全局一份**，写作页按书设置里不显示目标/柱状图
- 自定义字体只记路径、不复制字体文件：换电脑、挪走/删掉字体文件后会自动退回宋体
- 查找是**字面量**查找，不支持正则/通配符（`.*` 只是三个字符）
- 书架搜索只搜书名 / 文件夹名 / 章节名，不搜正文；章名命中的书卡只会打开书，不会直接跳到那一章
- 拖拽排序只支持在左栏内上下拖（不做多选、不做批量移动）
- 多窗口同时编辑两本书 → 留给 v0.5
- 章节状态只有**草稿 / 待修 / 完稿**三档（不做自定义状态、不按状态筛选/排序）；备注是一条 ≤200 字的一句话，不做多行便签、不进正文、也不参与搜索
- 复制本章（平台格式）**只复制正文、不含章名**，排版固定按「段首缩进两格 + 空一行（含缩进）」，不跟随「排版」对话框里记住的规则（不改标点 / 引号 / 文字）；空章不覆盖剪贴板
- 范围导出只作用于「导出 TXT」：「复制整本到剪贴板」始终是整本。按卷导出只列书里已有的卷（没分卷的书不显示这一项）；第 X–Y 章按**全书连续章号**算，导入的原文标题章节也按序号排，不按标题里的数字
- 「继续上次写作」只记**最近一本书**（不提供历史列表 / 最近打开的书单）；入口显示的是记录时的章号，若之后在别处删过章，点进去仍以书内 `lastOpenChapterId` 为准（失效时回退第 1 章）。上次那本书被删掉或移出书架后入口自动隐藏，不会提示「书不见了」
- Ctrl+G 跳章只在写作页生效，只匹配**当前这本书**的章节名（不做拼音/模糊纠错，不搜正文、不搜卷名）；输入纯数字按全书连续章号算，超出范围只提示不跳转；跳章本身不写正文，但切章会更新书目里的「上次打开章节」
- 同步冲突副本只检测**书文件夹顶层**的 `*conflicted*` / `*冲突副本*` 文件：不扫描子目录、不处理「整个书文件夹被同步盘复制成另一个文件夹」的情况，也**不提供自动合并**（冲突内容可能都没合并过，自动处理风险太大）。提示只针对当前书卡，处理完手动移走副本、回书架刷新即可
- `书目.json` 的 `schemaVersion` 目前是 1，迁移函数是空的（为将来加字段留口子）；旧版应用读新版本书目时只会保留版本号、按已知字段尽力读，不保证能理解将来版本新增的字段
- 「Windows 关机拦截」是尽力而为：系统关机不强等应用，可能来不及弹提示

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 书架是空的 | 书架目录里还没有书；点「新建一本书」，或把书文件夹放进该目录 |
| 书卡标红「书目损坏」 | 点开修复：从 `.bak` 恢复 / 从目录 txt 重建。不要自己删文件 |
| `pnpm start` 闪退、提示 `Cannot read properties of undefined (reading 'whenReady')` | 环境里有 `ELECTRON_RUN_AS_NODE=1`；确认用 `pnpm start`（走 scripts/start.js），或手动清掉该变量 |
| `pnpm start` 报「无法加载文件 …pnpm.ps1，因为在此系统上禁止运行脚本」 | Windows PowerShell 5.1 执行策略限制，与应用无关。改用 `pnpm.cmd start`、双击 `启动写作器.cmd`，或 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 后重试（详见「安装与启动」） |
| Electron 下载很慢/失败 | 检查 `.npmrc` 的镜像；或 `pnpm approve-builds` 放行 electron 的 install 脚本 |
| 记事本打开 txt 是乱码 | 章节文件是 UTF-8 无 BOM；较老的记事本请升级到 Win11 自带版本，或用 VSCode 打开 |
| 保存失败 | 看状态栏红字：磁盘满 / 文件被占用 / 无权限。处理后再按 `Ctrl+S`，关窗时也会阻止退出 |
| 想回退到昨天的版本 | 应用**默认没有每日自动备份**（按作者要求）。可以先去「设置 → 数据安全」打开**可选每日快照**（默认关）：开启后每次保存会把当天第一次的上一版留在书内 `_trash\快照-YYYYMMDD\`，之后可在「本书历史」里预览 / 还原。没开过快照时，先看「本书历史」能找回的替换 / 整理 / 删章备份和上一版 `书目.json.bak`；更早的版本请从你自己的同步盘 / 文件历史记录里找 |
| 「本书历史」在哪、能看到什么 | 写作页右上「导出 ▾ → 本书历史…」，或在书架右键书卡 →「本书历史…」。它把书内 `_trash` 的**替换备份 / 整理备份 / 还原前备份 / 每日快照 / 删除章节**和书文件夹里的上一版 `书目.json.bak` 按时间新→旧列出来，标出每个文件还在不在书里，可以预览原文、还原单章或整组。**只读扫描，不改文件**；还原前会把现在的内容再备份到 `_trash\还原前备份-时间戳\` |
| 删除的章节能找回吗 | 能试：右键书卡 →「本书历史…」→ 找「删除章节」那一组 →「放回书文件夹…」。txt 会原样回到书文件夹，但**不会自动加回章节列表**（避免乱改章号）；确实要完整找回时，再用书卡的修复 →「从目录重建」按目录里的 txt 重建书目（重建会生成新的书目 id、丢掉状态/备注和按书显示设置） |
| 书目.json.bak 能一键还原吗 | 不能，本书历史里的书目备份**只供预览**：旧书目可能和现在的章节文件对不上，自动覆盖风险太大。书目损坏请在书卡上点「修复」→「从备份恢复」，那条流程会先把损坏文件改名保留 |
| 本书历史里的「还原整组」会删掉备份吗 | 不会。备份只读、不消耗，可以重复还原；每次还原前还会把书里现在的内容再备份一份到 `_trash\还原前备份-时间戳\`。除了每日快照按保留天数清理自己生成的 `快照-YYYYMMDD` 目录，其它备份不会自动清理，嫌多可以自己按文件夹名删 |
| 书架上的「今天 +N 字」怎么算的 | 只算你**按保存**（`Ctrl+S` / 保存按钮 / 建章前自动保存）时，这一章比以前缓存字数多出来的**正字数**：没保存的输入不算，删字/改短也不倒扣。所以刚打了一段还没保存时数字不会动，按一下保存才涨。统计只写 `%APPDATA%\chapter-writer\stats.json`，不碰书库 |
| 怎么写每日目标 / 进度条怎么看 | 书架右上「设置 → 写作统计」，填每日目标字数（0 = 不设目标，默认关）。设了目标后，写作页状态栏会出现「今日 N 字 / 目标 M 字」和一条细进度条；书架顶部也会显示目标百分比，达标后标「已达标」。设置里还能看近 30 天柱状图（今天在最右） |
| 每日统计文件在哪、删了会怎样 | 在 `%APPDATA%\chapter-writer\stats.json`（不是书库）；删掉只丢历史统计，不影响小说和设置。文件坏了会归档成 `stats.json.corrupt-时间戳` 再从空统计继续，不会影响保存正文。旧版配置没有 `dailyGoal` 字段也照常启动（按不设目标处理） |
| 同时写几本书，今天字数怎么算 | 按天合计：今天所有书保存带来的新增字数都会加在一起；`stats.json` 里同时按书 id 分开记，删掉某本书也不会删掉它已经贡献过的当日字数 |
| 每日快照会自动帮我保存吗 | **不会**。快照只在你自己按 `Ctrl+S`（或建章前自动保存）时发生，跟着保存走：先留上一版、再写新正文。没按保存的内容仍然只在编辑区里，关窗前照常提醒 |
| 同一天改了十几次，快照会有十几份吗 | 不会。每章每天只留**当天第一份**（第一次保存前的上一版），后面再保存不会覆盖它；第二天再保存才会新建 `快照-新日期`。想找回当天更早的中间版本，目前只能靠 `Ctrl+Z` 或你自己的副本 |
| 快照会越积越多吗 | 会按你在设置里选的保留天数（1–90 天，默认 7）自动清理：每次保存时，删掉早于保留窗口的 `快照-YYYYMMDD` 目录。只删应用自己生成的这种目录，不认识的目录 / 散文件一律不动；关掉开关后不再新增也不清理 |
| 快照存在哪、怎么还原 | 每本书自己的 `_trash\快照-YYYYMMDD\`，文件名和章节 txt 一样。打开「本书历史」→ 找「每日快照」组 → 预览 / 还原单章 / 还原整组；还原前会把当前内容再备份到 `_trash\还原前备份-时间戳\` |
| 删除的小说去哪了 | 默认进 **Windows 回收站**（可还原）；回收站不可用（例如某些网络盘）时移到书架目录的 `_trash\`，同样不会真删 |
| 导入支持什么格式 | 支持三种：① 章节写作器自己的书文件夹（含合法 `书目.json`）→ 整本复制；② 一本书的章节 txt 文件夹（文件名带序号 `001-xxx.txt`，或 `第一章 xxx.txt`）→ 合成一本；③ 一堆完整小说 txt（每个 txt 是一整本小说）→ **默认「按原文章节导入」：按原文的「第X章 / 楔子」标题拆成多章，章名照抄原文、正文原样保留；也可以选「整本一章」不拆章。** 编码自动识别 UTF-8 / UTF-16 / GBK；原文件夹不会被移动或删除 |
| 排版会不会改坏我的稿子 | 「一键整理本章」只改空白和中文旁的半角标点（引号/省略号要你手动勾），**必须先看预览、点「套用到本章」才生效**，且只动当前章；套用后仍是未保存状态，不按 `Ctrl+S` 就不会写盘。不喜欢就 `Ctrl+Z` 退回 |
| 整理完发现不对，怎么回去 | `Ctrl+Z`，或「排版 ▾」→「撤销上次整理（可撤销 N 步）」，最多连退 50 步。撤销只退编辑区，不写盘；若已经按过 `Ctrl+S`，磁盘上就是整理后的内容（应用内没有备份，见上面三条提醒） |
| 为什么有的半角标点没转全角 | 规则只在**中文旁边**转，并跳过数字、英文、网址、时间（`3.14`、`www.a.com`、`12:30`、`A.开端`）和省略号 `...`，避免误伤正文。直引号/省略号要在「一键整理本章…」里单独勾，默认关 |
| 行距/正文底色/正文宽度会丢吗 | 全局默认和每本书的覆盖都保存在 `%APPDATA%\chapter-writer\config.json`，重启保持；手动删了配置文件会回到默认（行间距 1.95、通栏、原纸白）。这些设置**只改显示，不动正文** |
| 书架搜索怎么用 | 书架右上搜索框，或按 `Ctrl+F`；输入书名 / 文件夹名 / 章节名即过滤。`Enter` 打开第一本匹配的书，`Esc` 清空 |
| 为什么写作页里改的设置只影响这本书 | v0.3 起显示设置分两级：书架 →「设置」是全局默认；写作页里的预设 /「正文显示设置…」/ 章节栏宽度只记在当前这本书上。写作页设置弹层底部点「恢复本书默认」可以回到全局 |
| 「空一行（含缩进）」是什么 | 段落之间的空行不是纯空行，而是放两个全角空格（`　　`）。有些平台/编辑器会吃掉纯空行，粘过去就挤成一坨；带缩进的空行粘过去不会丢。口袋写作里叫「空一行（含缩进）」 |
| 想用自己下载的字体 | 「设置 → 字体 → 自定义字体」点「选择…」挑 `.ttf / .otf / .ttc` 文件，点「保存设置」生效；只读取不复制，字体文件挪走后会自动退回宋体。「恢复默认」一键回宋体 |
| 夜间模式在哪 | 「设置 → 背景 → 背景主题」选「夜间 · 深色」；还有牛皮纸、网格纸两档纹理。只换纸色/纹理，不改你的正文 |
| 选字体报「字体文件太大」 | 单个字体文件上限 24MB；换小一点的字体，或改用系统自带字体 |
| 整本替换点错了怎么办 | 重新打开「查找」面板，下方点「还原到替换前…」，二次确认即可（还原前会把当前内容再备份到 `_trash\还原前备份-时间戳\`）。更早的备份在书文件夹的 `_trash\替换备份-时间戳\` 里，可以打开「本书历史」选择对应的替换备份还原单章或整组；也可以手动拷回 |
| 「替换这一处」和「全部替换」有什么区别 | 「替换这一处」只改当前章编辑区里光标处的这一处（未保存，`Ctrl+S` 才写盘，可 `Ctrl+Z`）；「全部替换」在当前章也只是改编辑区，范围选「整本书」时才会直接写盘（写前自动备份、可还原） |
| 查找支持正则吗 | 不支持，按字面量找（`.*` 就是三个字符）。这样不会因为一条正则把全稿改坏；只想改一处用「替换这一处」 |
| 拖完章节，硬盘上的文件名乱了吗 | 没乱。拖拽只改 `书目.json` 的顺序，章节 txt 的文件名（创建序号）永远不变，界面上显示的「第N章」是按顺序现算的 |
| 拖不动章节？ | 按住左键上下拖，移动超过 5 像素才开始拖；松手生效。章节只有一章时不能拖 |
| 双击安装包被 Windows 拦了 | 安装包没做代码签名，SmartScreen 会提示。点「更多信息」→「仍要运行」即可；想彻底不提示需要买数字证书 |
| 安装到哪了？会删我的小说吗 | 默认装到当前用户目录（安装时可以改），桌面和开始菜单有快捷方式。**小说和配置都不在安装目录**，卸载不会删稿 |
| 安装版和 `pnpm start` 开发版数据互通吗 | 互通：都读同一个 `%APPDATA%\chapter-writer\config.json` 和同一个书架目录，换着开不会分裂 |
| 「一键整理本书」和「一键整理本章」什么关系 | 规则是同一套（沿用你上次在「整理本章」里定的）。「整理本章」只改编辑区、仍是未保存；「一键整理本书」是整本逐章**直接写盘**，写前把要改的章备份到 `_trash\整理备份-时间戳\`，已整理好的章不动 |
| 整本整理完后悔了怎么办 | 打开「本书历史」→ 选 `整理备份-时间戳` →「还原整组」或单章「还原」；还原前会先把现在的内容再备份到 `_trash\还原前备份-时间戳\`，点错了也还有退路。也仍可手动把备份里的 txt 按原文件名拷回书文件夹 |
| 建新章节时怎么不问我保不保存了 | v0.4 起：新建 / 插入章节前，如果当前章有未保存修改，会**自动先保存当前章**再建新章（作者要求的改动）。切章、关窗、返回书架仍然会问 |
| 导出的文件默认存哪 | 默认打开在**上一次导出保存到的文件夹**；第一次或那个文件夹已被删掉时用「文档」目录 |
| 能只导出某一卷 / 某几章吗 | 能。右上「导出 ▾」→「导出 TXT…」，在对话框里选「按卷导出」挑一卷，或选「第 X 章到第 Y 章」。默认文件名跟着范围走（`书名-卷名.txt` / `书名-第X-Y章.txt`），保存时可以改。导出文件里的章号仍按全书连续编号，不会从第 1 章重排；当前章没保存的内容也会一起导出（不写盘） |
| 打开应用怎么接着上次写 | 书架顶部有一条「继续写《书名》· 第N章」，点一下直接回到上次编辑的那一章；普通点书卡也会回到上次那章（书内 `书目.json` 的 `lastOpenChapterId`）。这条记录只记最近一本，书被删掉后会自动消失 |
| 章太多（一百多章）怎么快速跳 | 写作页按 `Ctrl+G`，输入章号（如 `12`、`第12章`）直接跳；或者输入章名的一部分（如「夜雨」），从结果里点一条。跳章不会改正文，当前章有未保存修改时会先问你保存 / 不保存 / 取消 |
| 能右键复制粘贴吗 | 能。正文、章节名、书名、书架搜索框、查找替换输入框里点右键都有「剪切 / 复制 / 粘贴 / 全选」；章节列表和书架卡片的右键是它们自己的菜单 |
| 怎么标记哪章写完了 / 哪章要改 | 右键章节 →「标记为完稿 / 待修 / 草稿」，名字前的小圆点会变绿/黄/灰；再右键 →「编辑备注…」写一句提醒（最多 200 字），鼠标悬浮在章节上能看到。书卡会显示「完稿 X/Y 章」。这些**只写 `书目.json`，正文 txt 不会变**；旧书没有这些字段也照常打开（默认草稿） |
| 书卡上的「检测到同步冲突副本」是什么 | 书架目录在 OneDrive / 坚果云里，两边同时改过同一本书时，同步盘会在书文件夹里多生成 `书目 (conflicted copy 1).json`、`001-起风-冲突副本.txt` 这类文件。写作器只标出来提醒，点提示能看到文件名、打开书文件夹；**不会自动合并或删除**，也不会把副本当章节。请手动对比后把要保留的内容合并回原章节，再把副本移走 |
| 书目.json 里的 schemaVersion 是什么，旧书会坏吗 | 是书目格式的版本号（当前 1），给以后加字段留的保险。旧书没有这个字段照常打开；只是打开不会改文件，等下次正常写盘才补上。不会碰章节 txt，也不需要手动处理 |
| 章节状态和备注会写进正文导出吗 | 不会。状态/备注只是写作进度标记，存在书目里；导出/复制的 txt 仍只有标题行和正文，一个字节都不多 |
| 复制本章和复制整本有什么区别 | 「复制整本」（右上「导出 ▾」）复制全书，带章名和卷名，当前章未保存内容也算；「复制本章（平台格式）」（右键章节或 `Ctrl+Shift+C`）只复制这一章**正文**，套好「段首缩进 + 空一行（含缩进）」再进剪贴板，方便直接贴到平台作者后台的正文框（章名在后台单独填）。两者都**不写盘** |
| 复制本章后章名去哪了 | 故意不带章名：起点/晋江等平台的作者后台，章节名和正文是两个输入框，带上章名还得删。需要章名时可在侧栏双击章节名复制 |
| 复制本章粘过去空行没丢吧 | 用的是「空一行（含缩进）」：段与段之间的空行里放了两个全角空格（`　　`），平台/编辑器吃掉纯空行时也不会挤成一坨。如果你的平台把带空格的空行也吞了，那是平台编辑器在收空白，可试试 `Ctrl+Shift+V` 纯文本粘贴 |
| 升级怎么办 | 直接双击新版本安装包覆盖安装即可；书架和配置不受影响（目前没有自动更新） |

## 后续候选（按需再做）

- 代码签名 + 自动更新（让 SmartScreen 不提示、点一下就能升级）
- 多窗口同时编辑两本书
- 正则查找（如果作者确实需要；现在为避免误伤只做字面量）
- 书架搜索加强：点「章节命中」直接跳到那一章、搜正文（现在只搜书名/章名；正文搜索要扫几千个 txt，得先做索引）
- 快照管理加强：在本书历史里按天折叠、批量清空某天的快照（现在按保留天数自动清理）
- 统计加强：按书/按月筛选、连续写作天数、导出统计图（现在只有今天 + 近 30 天柱状图）
- 灵感箱、敏感词预检、朗读、EPUB / DOCX 导出等发布层功能
- 想更贴口袋写作的话：背景图片 / 背景特效 / 主题色（需要往 `%APPDATA%` 存图片，不改书库）
- 若作者改变主意：可加回每日备份（自动保存只有建章前那一处，见上）
